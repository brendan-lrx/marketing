# LifestyleRx Brand — quick reference

## Typography

- **Averta** — everything. Extrabold (800) for headlines, Semibold/Bold (600/700) for labels and subheads, Regular (400) for body.
- **Thirsty Script Bold** — reserved for the words **"Better"** and **"Path"** only. Never for full sentences or headings.

## Colour

| Role | Hex |
|---|---|
| Brand green | `#7FC600` |
| Green, text on white | `#5E9300` |
| Green, small text on white | `#4C7700` |
| Green tint (panels) | `#F5FAEC` |
| Ink / slate | `#334155` |
| Secondary text | `#475569` / `#64748B` |
| Hairline | `#E2E8F0` |

Print rule: `#7FC600` is a graphic colour, not a text colour on white — it measures ~2.3:1. Use `#5E9300` or `#4C7700` for any type on a light ground.
